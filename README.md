# Projeto em conjunto
Esse projeto foi feito em grupo para a matéria de Design Profissional na UDF. A ideia principal foi aprender na prática como funciona o Git e o GitHub, trabalhando em branches, fazendo commits, revisando mudanças e entendendo como a colaboração funciona em um projeto real.

## Objetivo
Nosso objetivo foi aprender a organizar o trabalho em equipe usando controle de versão e também mexer um pouco no código HTML para entender melhor como uma página web é estruturada.

## Como visualizar
- Abra o arquivo [index.html](index.html) no navegador para ver a página do projeto.
- Esse README serve como uma apresentação simples do trabalho.

## O que aprendemos
- Git e GitHub
- Branches e commits
- Pull requests
- Revisão de código
- Resolução de conflitos
- Estrutura básica de HTML
